Bubble 0.4.1

This release focuses on extension safety, richer plugin output, and Swift 6 quality.

Plugin windows

  • Actions can open an HTML result window with bubble.showWindow().
  • Window handles support update, append, eval, and close for streaming AI or translation output.
  • Interactive windows can send form and button messages back to the action with bubbleHost.postMessage() and onMessage.
  • Native Copy, Close, and URL actions are available in result windows.

Extensions

  • Extension files are fingerprinted; changed or revoked packages are blocked until reviewed.
  • The Add menu manages installed extensions without a separate sheet.
  • Static action submenus and nested action paths are supported.
  • ESM imports/exports are converted for the Bubble JavaScript runtime.
  • Bundled libraries include axios, case-anything, js-yaml, linkedom, sucrase, and Turndown.
  • Secret options are stored outside action layout and Cloud sync.

OAuth

  • Module auth() supports API tokens and loopback authorization-code flows.
  • Stable callback port, provider error handling, and Sign In / Sign Out UI.

App and quality

  • Search palette for actions with folder and dynamic action support.
  • Result cards for long action output.
  • Swift 6 language mode with complete strict concurrency and zero source warnings.
  • Automatic menu-bar icon tinting with ellipsis.bubble.fill.
  • Updated app icon.

Bubble remains a local-first utility: no account, subscription, or in-app purchase is required.
