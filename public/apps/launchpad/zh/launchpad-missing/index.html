01

还在 15？先找回原生启动台。

macOS 15 仍然保留 Launchpad。如果只是 Dock 里的图标不见了，通常无需安装替代应用。

  1. 打开 Finder，在侧边栏选择「应用程序」。
  2. 找到「启动台 / Launchpad」，双击确认可以打开。
  3. 把 Launchpad 拖回 Dock 的应用图标区域。

也可以用 Spotlight 搜索「Launchpad」。如果仍找不到，先确认系统确实是 macOS 15。

02

刚升级？先试试系统自带的方法。

macOS 26 / 27 的应用入口已经改变。应用并没有随启动台一起消失，只是打开和浏览它们的方式不同了。

Spotlight
按 Command + 空格，输入应用名称并回车，适合已经知道要打开哪个应用。
Apps
从 Dock 打开「应用 / Apps」，浏览系统提供的应用列表。
Dock 文件夹
在 Finder 中把「应用程序」文件夹拖到 Dock 的文件夹区域，再从它的菜单选择以网格显示。

这些方法能打开应用，但不会恢复经典启动台的手动分页、文件夹和图标位置。如果你想保留按位置找应用的习惯，可以再看看 LaunchOS。

03

27 没有恢复经典启动台。

如果你留在 macOS 26，期待升级 27 后找回原来的启动台：macOS 27 没有带回经典 Launchpad，也没有恢复它的旧文件夹和手动分页方式。

你可以继续使用 Apps、Spotlight 和 Dock，或选择 LaunchOS 这样的独立应用，一键恢复熟悉的视觉浏览习惯。
