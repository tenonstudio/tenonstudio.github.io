Mac 启动台从 Dock 消失了？如何重新添加 Launchpad

2026年10月9日

原本放在 Dock（程序坞）里的启动台图标不见了，每次打开应用都要先去访达里找，或者输入名称搜索。能不能把熟悉的入口放回来？

如果你使用 macOS 15 或更早版本，通常可以将启动台重新拖回 Dock；如果你已升级到 macOS 26 或 27，经典启动台已被新的应用浏览方式替代，需要选择系统自带的入口，或使用 LaunchOS 这类启动台替代工具。

下面按你的情况操作。

先确认：图标被移除了，还是系统升级了？

点击屏幕左上角的苹果菜单，选择“关于本机”，查看 macOS 版本。

你的情况建议操作
macOS 15 或更早，只有 Dock 里的启动台图标不见了将启动台重新添加到 Dock
macOS 26 或 27，想从 Dock 浏览应用使用系统的应用入口，或添加“应用程序”文件夹
macOS 26 或 27，想找回全屏网格、文件夹和手动排序将 LaunchOS 添加到 Dock

从 Dock 移除图标，一般只会移除快捷入口，不会卸载对应应用。所以，先确认系统版本和应用是否仍然存在，再选择恢复方法。Apple 的 Dock 使用说明

macOS 15 或更早：把原版启动台拖回 Dock

如果没有升级系统，只是不小心把启动台图标拖出了 Dock，可以这样添加回来：

  1. 打开“访达”（Finder）。
  2. 在菜单栏选择“前往”→“应用程序”。
  3. 找到“启动台”（Launchpad）。
  4. 将它拖到 Dock 的应用图标区域。Dock 位于屏幕底部时，这通常是分隔线左侧。
  5. 等其他图标让出位置后，松开鼠标。
  6. 点击刚添加的图标，确认能打开启动台。

如果“应用程序”文件夹里没有显示启动台，可以在访达中按 Shift + Command + G，输入 /System/Applications，再查找“启动台”。

这里拖动的是 Dock 快捷入口，不需要把启动台应用移出原来的文件夹。重新添加图标也不会重新排列启动台里的应用。

Apple 的 macOS 15 使用手册仍提供通过 Dock 打开启动台的操作说明。查看原版启动台说明

如果确认是旧系统，却仍找不到启动台，先重启 Mac 再检查；这时问题可能不只是 Dock 图标被移除，不必直接重置整个 Dock。

macOS 26 或 27：原来的启动台入口发生了变化

如果启动台是在升级系统之后消失的，重新拖图标通常不能找回经典 Launchpad。

新版 macOS 使用与“聚焦”（Spotlight）整合的应用浏览界面。你仍然可以查看应用并点击打开，但它与原来按页面、文件夹和手动位置整理应用的启动台不同。Apple 的新版应用浏览说明

接下来，可以根据自己想要的体验选择两种方式。

方法一：把“应用程序”文件夹添加到 Dock

如果你只想点击 Dock 上的一个图标，就能看到应用列表，可以先试试系统自带的文件夹网格。

  1. 打开访达，选择菜单栏中的“前往”→“前往文件夹”。
  2. 输入 /，按下 Return，找到“应用程序”文件夹。
  3. 将这个文件夹拖到 Dock 的文件夹区域。Dock 位于屏幕底部时，这通常是分隔线右侧、废纸篓附近。
  4. 松开鼠标，添加文件夹入口。
  5. 右键点击 Dock 中的“应用程序”文件夹，在“查看内容为”中选择“网格”。
  6. 如果希望显示文件夹图标，可在“显示为”中选择“文件夹”。

现在，点击这个入口，就能展开应用图标并打开应用。Apple 支持在 Dock 中用网格、列表或扇形查看文件夹内容。查看文件夹显示说明

拖应用图标和拖文件夹，要放在 Dock 的不同区域。 如果一直拖不进去，先检查是否放错了分隔线的一侧。

这个方案免费、无需安装额外工具，适合想快速浏览应用的人。不过，展开的是文件夹内容，不会恢复经典启动台的全屏分页、拖拽分组或旧布局。

方法二：把 LaunchOS 添加到 Dock，找回启动台式体验

如果你想恢复“点击 Dock 图标，打开全屏应用网格”的习惯，并继续使用文件夹、分页和手动排序，可以使用 LaunchOS。

LaunchOS 支持 macOS 26 及更新版本，提供免费的 Basic 版，可用于核心启动台式体验。它是独立的 Mac 应用，提供熟悉的视觉浏览和整理方式。

安装并添加 Dock 入口

  1. 从 LaunchOS 官网 下载应用。
  2. 打开下载的安装文件，将 LaunchOS 拖入“应用程序”文件夹。
  3. 在访达的“应用程序”中找到 LaunchOS，将它拖到 Dock 的应用图标区域。
  4. 点击 Dock 中的 LaunchOS 图标，打开应用网格。
  5. 按照自己的习惯拖动应用、创建文件夹并整理页面。

这样，你可以继续从 Dock 一键打开启动台式界面。

如果你希望沿用旧文件夹和应用顺序，也可以使用 LaunchOS 的原生启动台布局导入功能。能否导入取决于旧布局数据是否仍然可用；添加 Dock 图标本身不会自动恢复原来的布局。

只需要 Dock 入口时，先完成上述设置即可。手势、F4 和其他快捷方式可以之后再按需配置。

常见问题

从 Dock 移除启动台，会删除里面的应用吗？

不会。从 Dock 移除图标只是移除入口。已经安装的应用仍在 Mac 上，可以通过访达或聚焦打开。

为什么刚才有图标，退出应用后就不见了？

普通应用运行时可能会临时出现在 Dock 中。对于 LaunchOS 等应用，可以右键点击图标，选择“选项”→“在程序坞中保留”，或者从“应用程序”文件夹拖入 Dock，将入口固定下来。

把启动台放回 Dock，需要重置 Dock 吗？

只是缺少一个图标时，通常不需要。重置 Dock 可能改变已有的固定图标和布局，先尝试重新添加对应应用或文件夹。

macOS 26 或 27 能直接把 Apple 原版启动台拖回来吗？

不能通过添加 Dock 图标恢复已经被替代的经典启动台。你可以使用系统现有的应用浏览方式，也可以添加 LaunchOS，恢复全屏网格、文件夹和分页等熟悉的操作。

LaunchOS 能完全替代 Spotlight 吗？

它们适合不同的使用习惯。知道应用名称时，可以继续用 Spotlight 搜索；想看图标、按文件夹和位置寻找应用时，可以点击 Dock 中的 LaunchOS。

如果你想找回的是后者，可以先 下载免费的 LaunchOS Basic 版，把它放回你习惯点击的位置。
