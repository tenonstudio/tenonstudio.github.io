01

15なら、まず標準のLaunchpadを戻しましょう。

macOS 15にはLaunchpadが残っています。Dockのアイコンだけが消えた場合、通常は代替アプリをインストールする必要はありません。

  1. Finderを開き、サイドバーの「アプリケーション」を選びます。
  2. 「Launchpad」を見つけ、ダブルクリックして開けることを確認します。
  3. LaunchpadをDockのアプリ領域へドラッグします。

Spotlightで「Launchpad」を検索することもできます。見つからない場合は、macOS 15を使っているか確認してください。

02

アップデート直後なら、まず標準機能を試しましょう。

macOS 26 / 27ではアプリを開く入口が変わりました。アプリ自体がLaunchpadと一緒に消えたわけではなく、開き方と探し方が変わっています。

Spotlight
Command + Spaceを押し、アプリ名を入力してReturnを押します。開きたいアプリが決まっているときに便利です。
Apps
Dockから「アプリ / Apps」を開き、macOSのアプリ一覧を参照します。
Dockのフォルダ
Finderの「アプリケーション」フォルダをDockのフォルダ領域へドラッグし、表示形式をグリッドにします。

これらの方法でアプリは開けますが、以前のLaunchpadにあった手動ページ、フォルダ、アイコン位置は戻りません。場所でアプリを覚えているなら、LaunchOSも確認してください。

使い慣れた自由配置とフォルダ体験を取り戻す ↓
03

macOS 27でも以前のLaunchpadは戻りません。

macOS 26のまま、27へのアップデートでLaunchpadが戻るのを待っている方へ。macOS 27では以前のLaunchpadも、そのフォルダや手動ページも復活しません。

Apps、Spotlight、Dockを使い続けるか、LaunchOSのような独立アプリで、使い慣れた視覚的なブラウジング体験をすぐに取り戻せます。

以前のレイアウトを使いたい？まず古いデータが残っているか確認してください。

読み取り可能で互換性のある以前のLaunchpadデータが必要です。上書きアップデート、クリーンインストール、Macの移行、データ削除などで結果は異なるため、復元は保証できません。先にバックアップを残し、データがなければ手動で作り直してください。

無料版とPro

まずBasicを使い、必要ならProへ。

Basic

基本機能を無料で。

使い慣れた自由配置のアプリグリッド、フォルダ、基本的な整理機能で、日常の起動習慣を取り戻せます。

Basicは無料
Pro

起動方法とカスタマイズを追加。

トラックパッドジェスチャー、F4、ホットコーナー、カスタムグリッドなどはPro機能です。

任意の権限

必要になったときだけ有効に。

基本的なアプリの閲覧と起動には、次の権限は必要ありません。

アクセシビリティ
F4やトラックパッドジェスチャーなど、任意のシステム全体の起動方法に使います。対応機能を有効にするときに許可してください。
フルディスクアクセス
「完全アンインストール」で、選択したアプリの関連ファイルを探す場合だけ使います。アプリの閲覧や起動には必要ありません。
