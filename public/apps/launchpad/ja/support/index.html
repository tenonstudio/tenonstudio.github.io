注文とライセンス

お支払い後、領収書とライセンスメールの2通が届きます。ライセンスメールは領収書より数分遅れて届く場合があります。
領収書のみが届いた場合は、迷惑メールフォルダを確認してください。プロバイダーによって迷惑メールとして分類されている可能性があります。
どちらのメールも届かない場合は、入力したメールアドレスが間違っているか、メールサービスで受信できない状態である可能性があります。
どのような状況でもご安心ください。以下のメールアドレスまでお問い合わせいただければ解決いたします。

購入時のメールアドレスを利用できる場合は、「ライセンスを探す」からライセンスを再送できます。

もちろんあります！LaunchOS には Basic と PRO の 2 つのプランがあります。Basic プランは完全無料ですが、PRO プランには 7 日間の無料トライアルが含まれています。トライアル期間終了後、アクティベーションを行うか、Basic プランを引き続き利用するかを選択できます。

「ライセンスを探す」から、ライセンスをご自身のメールアドレスに再送できます。

購入時のメールアドレスが使えない場合は、請求書、注文履歴、支払い記録など、ライセンスの所有を確認できる情報を添えて、公式メールアドレスまでお問い合わせください。ライセンスの復旧をお手伝いします。

「ライセンスのメールアドレスを変更」から変更できます。元のメールアドレスが使えない場合は、請求書、注文履歴、支払い記録など、ライセンスの所有を確認できる情報を添えて、公式メールアドレスまでお問い合わせください。変更をお手伝いします。

Mac がインターネットに接続されていることを確認してください。
Clash、Surge、AdGuard、Little Snitch、LuLu などのネットワークプロキシ、ファイアウォール、セキュリティツールを使用している場合は、一時的に終了するか、LaunchOS のネットワークアクセスを許可してから再度アクティベーションをお試しください。
問題が解決しない場合は、スマートフォンのテザリングなど別のネットワークに切り替えて再度お試しください。
それでもアクティベーションできない場合は、launchos@remixdesign.app までお問い合わせください。

古いデバイスをまだ使用できる場合：
古いデバイスで LaunchOS を開き、「設定」→「このアプリについて」→「デバイス管理」に進んで古いデバイスを削除した後、新しいデバイスでアクティベーションしてください。
古いデバイスを使用できない場合：
新しいデバイスでそのままアクティベーションしてください。ライセンスが使用中、またはデバイス数の上限に達していると表示されたら、ダイアログの「デバイス管理」をクリックし、古いデバイスを削除してアクティベーションを続けてください。

支払いの失敗は、取引のリスク管理や銀行の承認処理によって発生することがあります。カードや決済口座に引き落としが表示されている場合、通常は 1〜5 営業日以内に元の支払い方法へ自動的に返金されます。後ほど明細をご確認ください。5 営業日を過ぎても返金されない場合は、支払い記録を添えて launchos@remixdesign.app までお問い合わせください。

申し訳ありませんが、現在は教育機関向け割引を提供していません。

ご利用中に問題があれば、このページ上部の公式メールアドレスまでお問い合わせください。定期的に修正版を提供しており、問題の解決をお手伝いします。

問題が解決しない場合は、購入から 14 日以内に Paddle で返金を申請できます。適用条件は返金ポリシーをご覧ください。

購入画面には、お住まいの国や地域で利用できる支払い方法が表示されます。国や地域の表示が正しくなく、VPN を使用している場合は、VPN をオフにして購入画面を開き直してください。

ロシアやベラルーシなど、一部の地域では現在購入できません。今後、より多くの地域でお支払いいただける方法を検討しています。

使い方と機能

まず、Pro が有効になっているか、試用期間内であること、および必要なシステム権限が許可されていることを確認してください。それでも使用できない場合は、LaunchOS の権限を一度削除して追加し直してください。
LaunchOS を終了し、「システム設定」>「プライバシーとセキュリティ」>「デバイスの制御とデータへのアクセス」（macOS 26 では「アクセシビリティ」）を開きます。一覧から LaunchOS を削除し、下の「+」で追加し直して、権限が有効になっていることを確認してください。

LaunchOS のログイン項目を一度削除し、追加し直してください。LaunchOS を終了し、「システム設定」>「一般」>「ログイン項目と機能拡張」を開きます。「ログイン時に開く」の一覧で LaunchOS を選択し、下の「–」で削除してから「+」で追加し直します。また、「バックグラウンドでのアプリの動作」（Background App Activity）にある LaunchOS のスイッチがオンになっていることも確認してください。その後 LaunchOS を開き、設定で「ログイン時に起動」を再度有効にしてください。

LaunchOSのDock機能拡張がオフになっているか、まだ有効になっていない可能性があります。
「システム設定」＞「一般」＞「ログイン項目と機能拡張」を開きます。「機能拡張」でLaunchOSを探し、右側の「情報」ボタン（ⓘ）をクリックして、Dock機能拡張をオンにしてください。その後、LaunchOSを終了して開き直すと、新しいDockアイコンが反映されます。

プライバシーと安全性

はい。LaunchOS は Apple Developer ID 証明書で署名され、Apple の公証（Notarization）を受けています。SIP の無効化、保護されたシステムファイルの変更、macOS のダウングレードは必要ありません。
インターネット接続が必要なのは PRO ライセンスの状態確認時のみで、それ以外の主要機能は Mac 上で完全にローカル動作します。App の一覧、レイアウト、フォルダ、設定などのユーザーデータは端末内だけに保存され、アップロードされません。現在のバージョンにはテレメトリや行動分析モジュールもありません。メールアドレスは、注文照会、ライセンス送付、ライセンス復旧のサポートにのみ使用します。詳しくはプライバシーポリシーをご覧ください。

App Store の審査ルールにより、第三者開発者は通常、システム標準アプリを再現する製品を公開できません。元のアプリが新しいシステムで使えなくなっている場合でも同じです。LaunchOS はクラシックな Launchpad 体験を高い精度で復元しているため、App Store 配布には向いていません。
LaunchOS の決済は Paddle によって処理されます。Paddle は CleanMyMac の開発元である MacPaw などのソフトウェア企業にも採用されており、支払い情報を保護します。私たちが収集するメールアドレスは、ライセンスの送付、復元、漏洩時のリセットなど、ライセンス管理に必要な用途に限られます。

LaunchOS は launchosapp.com、または公式サイトに掲載されたダウンロードリンクからのみ入手してください。正規版は Developer ID 証明書で署名され、Apple の公証を受けているため、通常は macOS Gatekeeper が認識し、セキュリティ保護を回避する必要はありません。「開発元を確認できない」「App が壊れている」と表示されたり、「プライバシーとセキュリティ」で「このまま開く」よう求められたりした場合、その表示だけで安全とも改ざん済みとも断定できません。ファイルを削除し、公式サイトから再度ダウンロードしてください。
ターミナルに慣れている場合は、spctl --assess --type execute --verbose=4 /Applications/LaunchOS.app を実行できます。有効な公式ビルドでは accepted と表示され、公証済み Developer ID がソースとして示されます。

macOS 26 では、F4 キーやトラックパッドジェスチャなどの任意の起動方法に「アクセシビリティ」権限を使用します。macOS 27 では、Apple が同じ権限を「システム設定」→「プライバシーとセキュリティ」→「デバイスの制御とデータへのアクセス」に移しました。この権限は、任意の起動方法に必要な入力の受信または実行にのみ使われ、LaunchOS にデータのアップロードを許可するものではありません。
「フルディスクアクセス」は別の権限で、完全アンインストール時に関連ファイルを検索して削除するためにのみ使用します。各権限は対応する機能を使うときだけ要求され、通常の App の閲覧や起動には必要ありません。

ごくまれに、macOS がキーチェーンへのアクセス要求を表示することがあります。LaunchOS が、キーチェーン内にある LaunchOS と無関係なパスワードや個人情報を読み取ったり収集したりすることはありません。
この問題が発生した場合は、LaunchOS を終了し、Spotlight で「キーチェーンアクセス」（「パスワード」アプリではありません）を検索して開き、LaunchOS に関連する項目を検索して削除してから、LaunchOS を再起動してください。

その他の質問

はい。LaunchOS は、多くのユーザーが実際に恋しがっている部分を中心に作られています。全画面のアプリグリッド、フォルダ、ドラッグ＆ドロップ整理、視覚的なブラウズ、空間記憶、慣れた起動方法です。Apple 純正の Launchpad ではありませんが、macOS 26 Tahoe と macOS 27 Golden Gate 上でそのワークフローに近い体験を目指しています。
