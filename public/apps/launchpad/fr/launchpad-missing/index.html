01

Toujours le 15 ? Restaurez d'abord le Launchpad intégré.

macOS 15 inclut toujours Launchpad. S'il manque uniquement l'icône Dock, vous n'avez généralement pas besoin d'une application alternative.

  1. Ouvrez Finder et choisissez Applications dans la barre latérale.
  2. Recherchez Launchpad et double-cliquez dessus pour vous assurer qu'il s'ouvre.
  3. Faites glisser Launchpad vers la zone d'application du Dock.

Vous pouvez également rechercher « Launchpad » avec Spotlight. S'il manque toujours, vérifiez d'abord que votre Mac exécute macOS 15.

02

Vous venez de mettre à niveau ? Essayez d'abord les options intégrées.

Les points d'entrée des applications ont changé dans macOS 26/27. Vos applications n'ont pas disparu avec Launchpad : la façon dont vous les ouvrez et les parcourez a changé.

Spotlight
Appuyez sur Commande + Espace, saisissez un nom d'application et appuyez sur Retour. Mieux encore, lorsque vous savez déjà quelle application vous souhaitez.
Applications
Ouvrez les applications du Dock pour parcourir la liste des applications fournie par macOS.
Dossier Dock
Faites glisser le dossier Applications de Finder vers la zone des dossiers de Dock, puis choisissez Grille comme style d'affichage.

Ces méthodes ouvrent les applications, mais elles ne restaurent pas les pages de manuel, les dossiers ou les positions des icônes du Launchpad classique. Si vous trouvez des applications par emplacement, jetez un œil à LaunchOS.

Restaurez l'arrangement gratuit et l'expérience des dossiers que vous connaissez ↓
03

macOS 27 n'a pas restauré le classique Launchpad.

Si vous restez sur macOS 26 et attendez que le 27 ramène Launchpad : macOS 27 ne restaure pas le Launchpad classique, ses anciens dossiers ou pages de manuel.

Vous pouvez continuer à utiliser les applications Spotlight et Dock, ou utiliser une application indépendante telle que LaunchOS pour restaurer l'expérience de navigation visuelle familière en une seule étape.

Commencez en trois étapes

Remettez Launchpad sur votre Mac

  1. 01

    Téléchargez la version stable

    Confirmez que votre Mac répond à la configuration système requise, puis obtenez le DMG à partir du bouton de téléchargement officiel sur cette page.

  2. 02

    Déplacez-le vers Applications

    Ouvrez le DMG, faites glisser LaunchOS dans le dossier Applications, puis ouvrez LaunchOS.

  3. 03

    Organisez-le à votre façon

    Parcourez les applications, créez des dossiers et ajustez leur ordre. Activez F4 ou les gestes uniquement lorsque vous avez besoin de ces commandes.

Vous voulez votre ancienne mise en page ? Vérifiez d'abord si les anciennes données sont toujours disponibles.

L’importation nécessite des données Launchpad existantes lisibles et compatibles. Une mise à niveau sur place, une nouvelle installation, une migration vers un nouveau Mac ou un nettoyage des données peuvent produire des résultats différents, la récupération n'est donc pas garantie. Conservez une sauvegarde avant d’importer. S'il ne reste aucune donnée utilisable, reconstruisez manuellement les dossiers et l'ordre des applications.
