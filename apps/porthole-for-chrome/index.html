Porthole
for ChromePorthole
for Chrome

A floating window into any webpage. 为网页任意区域，开一扇悬浮的窗。

Select an element, drag a region, or mirror a whole page into a Picture-in-Picture window. Porthole for Chrome keeps live web content visible while you work elsewhere. 选择元素、拖拽区域，或把整个页面放进画中画窗口。Porthole for Chrome 让网页内容一直可见，同时你可以继续做别的事。

What it does它能做什么

Keep a piece of the web beside you.把网页的一角留在身边。

The extension is designed for reference material: a chart, a chat, a score, a live feed, or a paragraph you need while writing somewhere else.它适合参考资料：行情、聊天、比分、直播，或写作时需要一直看着的一段内容。

01

Smart select智能选择

Hover and click any element, or drag a custom region. Whole-page mode is there when you need it.悬停点击任意元素，或拖拽自定义区域；需要时也可以镜像整个页面。

02

Multi-select多选模式

Mirror several elements at once, sharing one floating window.一次镜像多个元素，共用同一个悬浮窗。

03

Cross-page跨网页

Bring elements from different pages into one floating view for comparison.把不同页面的内容放进同一个悬浮窗，方便对比。

04

Scroll to zoom滚轮缩放

Scroll over a mirror to zoom in or out while the source keeps rendering live.在镜像上滚动即可缩放，来源仍然实时渲染。

05

Picture-in-Picture画中画

A small always-on-top window that follows you across tabs and apps.一个小巧的置顶窗口，切换标签页和应用也不会消失。

06

No account无需账号

Free, no license key, no account. Install it and start mirroring.免费，无需激活码或账号，安装即可使用。

Stays in the browser留在浏览器里The mirror is rendered locally; no account or upload.镜像在本地渲染，不需要账号，也不会上传内容。

A small tool for big tabs给大页面一个小窗口

Useful when switching tabs is the problem.当问题变成“不停切标签页”。

Keep a reference piece of a page visible while you write, code, trade, or watch something else. Porthole for Chrome makes that piece a small floating window instead of another tab.写作、写代码、看盘或看视频时，把需要的网页片段留在眼前。它是一扇小悬浮窗，而不是又一个标签页。

Select once. The mirror stays live, so a score, a chart, or a chat updates without refreshing a second copy of the page.选择一次，镜像保持实时更新。比分、图表、聊天都能直接刷新，不用重新开一份页面。

Need more than one piece? Switch on multi-select or cross-page mode and build one view from the parts that matter.需要更多内容？打开多选或跨网页模式，把真正相关的几块拼成一个视图。
